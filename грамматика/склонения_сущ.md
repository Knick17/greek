
**Единственное число**

|Падеж|Мужской|Женский|Средний|
|---|---|---|---|
|Именительный|ο + -ος / -ής / -ας|η + -α / -η|το + -ο / -ι / -μα|
|Родительный|του + -ου / -η / -α|της + -ας / -ης|του + -ου / -ιού / -ματος|
|Винительный|τον + -ο / -η / -α|τη(ν) + -α / -η|το + -ο / -ι / -μα|
|Звательный|без артикля -ε / -η / -α|без артикля -α / -η|без артикля -ο / -ι / -μα|

**Множественное число**

|Падеж|Мужской|Женский|Средний|
|---|---|---|---|
|Именительный|οι + -οι / -ες|οι + -ες / -εις|τα + -α / -ά / -ματα|
|Родительный|των + -ων|των + -ων / -εων|των + -ων|
|Винительный|τους + -ους / -ες|τις + -ες / -εις|τα + -α / -ά / -ματα|
|Звательный|без артикля -οι / -ες|без артикля -ες / -εις|без артикля -α / -ά / -ματα|
## Основные правила

1. **Средний род** почти не меняется в винительном и звательном падежах: там всегда форма именительного.
2. **Винительный мужского рода** образуется от родительного: τον άνθρωπο, τον φοιτητή, τον τουρίστα. Артикль τον обязателен.
3. **Звательный падеж** в основном используется в разговорной речи и с именами. Для мужского рода на -ος он оканчивается на -ε (άνθρωπε), для -ης на -η, для -ας на -α.
4. **Родительный падеж множественного числа** почти всегда на -ων. Исключение: женский род на -η, там -εων (πόλεων).
5. **Заимствованные слова** часто несклоняемы: ταξί, ντίβι (TV) и т. п. Такие слова сохраняют одну форму во всех падежах.

Если нужна версия для древнегреческого (3 склонения по основе, 5 падежей и дательный), могу построить аналогичное дерево.
